# DavenportConstantDB

This is a database of Davenport constants for abelian groups of order up to 500, by Jessica Han (jjhan@colgate.edu) and Jacob Mayle (mayle@udel.edu).

The data for abelian groups comes from the [Abstract groups](https://www.lmfdb.org/Groups/Abstract/) database in the LMFDB. In particular, the labeling scheme is that of the Small Groups Library, as explained [here](https://www.lmfdb.org/Groups/Abstract/Labels).

The eventual goal of this project is to provide [Lean](https://lean-lang.org/) proofs for the Davenport constants in the database. For now, each constant has an associated "Justification" giving a reference to the literature. A full list of citations is forthcoming.

As far as we are aware, the Davenport constant is unknown for 30 of the 1012 abelian groups of order up to 500. These are marked "Appears to be unknown" in the data file. If you are aware of the Davenport constant for any of these groups, please let us know. In addition, we welcome any questions, comments, or suggestions.
